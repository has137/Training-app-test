# عزم — تطبيق تدريب منزلي

تطبيق تمارين بالعربية ومن اليمين لليسار، ملف واحد يعمل بدون إنترنت على iPhone وiPad.
يجمع القوة وشكل V والملاكمة واللياقة وصحة المفاصل في برنامج واحد مبني على البحث.

## الملفات المهمة

| الملف | ما هو |
|---|---|
| `index.html` | التطبيق كاملاً في ملف واحد (الخطوط والرسوم والبيانات داخله) |
| `research.md` | البحث: 39 مصدراً مع الروابط ومستوى الدليل لكل قرار |
| `program.md` | البرنامج مكتوباً: الأسبوع، والتمارين، وجدول العضلات، وخطة المفاصل، وقواعد التطور |
| `src/data/program.js` | بيانات البرنامج والتمارين، منفصلة عن الواجهة |
| `src/data/figures.js` | وضعيات الرسوم التوضيحية لكل تمرين |
| `src/js/` | كود الواجهة والمنطق |
| `manifest.webmanifest` و `sw.js` و `icons/` | للتثبيت على الشاشة الرئيسية والعمل بدون إنترنت عند الاستضافة |

## التثبيت على iPhone أو iPad

### الطريقة 1: عبر GitHub Pages (الأفضل، يعمل بدون إنترنت)

| الخطوة | ماذا تفعل |
|---|---|
| 1 | في GitHub افتح المستودع، ثم Settings، ثم Pages |
| 2 | في Source اختر Deploy from a branch، ثم الفرع والمجلد `/ (root)` |
| 3 | انتظر دقيقة حتى يظهر الرابط |
| 4 | افتح الرابط في Safari على iPhone أو iPad |
| 5 | اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية» |

بعد أول فتح، يعمل التطبيق بدون إنترنت. بياناتك تبقى على الجهاز، وخذ نسخة احتياطية من الإعدادات.

ملاحظة: GitHub Pages للمستودعات الخاصة يحتاج اشتراكاً مدفوعاً في GitHub.

### الطريقة 2: رابط Claude

نسخة `dist/artifact.html` منشورة كصفحة على Claude. تحفظ بياناتك في حسابك أيضاً، فتظهر على iPhone وiPad معاً.
تحتاج تسجيل الدخول إلى Claude، والإنترنت عند الفتح.

## البناء والاختبار

| الأمر | ماذا يفعل |
|---|---|
| `node tools/validate.cjs` | يتأكد أن كل تمرين وبديل ورسم مذكور في البيانات موجود |
| `node tools/build.mjs` | يبني `index.html` و`dist/artifact.html` وملفات التثبيت |
| `node tools/e2e.mjs` | يجرّب التطبيق في متصفح بعرض 390 بكسل: جلسة كاملة، وناقصة، وتبديل، وإضافة مجموعة، ونشاط حر، والخروج والعودة |
| `node tools/logic-test.mjs` | يختبر قواعد التطور: زيادة الوزن، ونفاد الأوزان، والانقطاع، والتخفيف، والسلالم، والكاحل |
